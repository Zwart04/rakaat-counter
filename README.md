# 🕋 Rakaat Counter: Solusi buat yang suka lupa rakaat sholat

Aplikasi web pendeteksi rakaat & sujud otomatis menggunakan sensor bayangan kamera depan. **Tanpa instalasi & 100% offline.**

> 🚀 **[Coba Demo Live](https://zwart04.github.io/rakaat-counter/)**

![Cara Penggunaan](https://raw.githubusercontent.com/Zwart04/rakaat-counter/main/demo.png)

> *Catatan:* Gambar di atas hanyalah contoh tampilan. Saat membuka link, aplikasi akan meminta akses kamera untuk mendeteksi intensitas cahaya.

---

## ⚡ Keunggulan Utama
- **Anti-Salah Sentuh (Zero-Touch)**: Semua tombol UI otomatis terkunci saat sholat dimulai. Tidak akan batal/tergeser jika sajadah atau sajadah lipat menyentuh layar HP.
- **Deteksi Otomatis**: Menghitung sujud & rakaat menggunakan sensor bayangan tubuh (kamera depan).
- **Panduan Suara**: Suara pemandu "Sujud satu", "Rakaat X" (tersedia pilihan suara Laki-laki / Perempuan).
- **Aman & Privat**: Kamera hanya diproses di browser lokal HP, tidak ada perekaman atau pengiriman data ke internet.

---

## 💡 Tips Penggunaan Maksimal
> ⚠️ **Sangat Disarankan:** Aktifkan **Mode Pesawat (Airplane Mode)** dan **Jangan Ganggu (Do Not Disturb)** pada HP Anda sebelum sholat agar hitungan tidak terganggu oleh panggilan telepon atau notifikasi WhatsApp masuk.

---

## 🛠 Cara Pakai Singkat
1. Buka [Link Demo](https://zwart04.github.io/rakaat-counter/).
2. Izinkan akses kamera.
3. Pilih suara pemandu, lalu klik **Mulai Sholat**.
4. Letakkan HP di samping sajadah (sejajar dengan posisi kepala saat sujud).
5. Selesai sholat, tekan **Reset** untuk mengulang.
